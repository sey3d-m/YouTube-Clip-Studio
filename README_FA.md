# YouTube Clip Studio — نسخه GitHub Actions

یک سامانه نیمه‌خودکار برای تبدیل **یک ویدئوی بلند به چند کلیپ عمودی** یا تهیه بسته انتشار برای **یک کلیپ آماده**. تحلیل محتوایی با Gemini و خروجی ویدئو با FFmpeg انجام می‌شود. رایانه شما هنگام پردازش لازم نیست روشن باشد.

## راه‌اندازی فقط برای بار اول

1. در GitHub یک **Private repository** مثلاً `youtube-clip-studio` بسازید.
2. محتوای این پوشه را با حفظ ساختار، شامل پوشه پنهان `.github/workflows`، به ریپازیتوری منتقل کنید. ساده‌ترین روش برای ویندوز: نرم‌افزار **GitHub Desktop** → Clone repository → کپی فایل‌های استخراج‌شده به پوشه پروژه → Commit to main → Push origin. *فایل ZIP را بدون استخراج صرفاً به‌عنوان یک فایل آپلود نکنید.*
3. در GitHub به `Settings → Secrets and variables → Actions → New repository secret` بروید. نام Secret: `GEMINI_API_KEY` و مقدار آن کلید API خود از [Google AI Studio](https://aistudio.google.com/app/apikey) باشد. کلید را در فایل یا پیام عمومی نگذارید.
4. `Actions → YouTube Clip Studio → Run workflow` را باز کنید؛ اگر Actions غیرفعال است فعال کنید. لینک ویدئو و پارامترها را وارد کرده و Run workflow بزنید.
5. پس از موفقیت، وارد همان Run شوید؛ پایین صفحه در بخش **Artifacts**، فایل `youtube-studio-...` را دریافت و استخراج کنید. `dashboard.html` نمای گزارش را نشان می‌دهد.

> نکته: فایل workflow باید روی شاخه پیش‌فرض مخزن (معمولاً main) موجود باشد تا Run workflow نمایش داده شود.

## گزینه‌های فرم

| گزینه | کارکرد |
|---|---|
| video_url | لینک مستقیم MP4/MOV/MKV قابل دریافت، Google Drive قابل‌دسترسی با لینک، یا YouTube عمومی |
| mode: automatic | از ویدئوی بلند چند بخش جذاب و غیرهمپوشان انتخاب و برش می‌زند |
| mode: precut | برای یک کلیپ ازپیش‌آماده، خود کلیپ را حفظ و فقط بسته انتشار و نسخه عمودی تولید می‌کند |
| language | فارسی `fa`، بنگالی `bn`، عربی `ar`، انگلیسی `en` |
| count | حداکثر تعداد کلیپ (فقط automatic) |
| min_seconds / max_seconds | بازه طول هر کلیپ در حالت automatic؛ پیش‌فرض ۲۵ تا ۶۵ ثانیه |
| subject | اولویت محتوا، موضوع تخصصی، لحن و محدودیت‌ها |
| model | `gemini-3.8-flash` با کیفیت بالاتر یا `gemini-3.5-flash-lite` اقتصادی |

**Google Drive:** فایل را در Drive آپلود کنید → Share → General access → **Anyone with the link** → Viewer → Copy link. این شیوه برای فیلم‌های محرمانه مناسب نیست چون دریافت از طریق لینک برای دیگران هم ممکن است. فایل بسیار بزرگ یا محدودیت دانلود Drive ممکن است باعث خطا شود. برای رسانه‌های محرمانه در نسخه بعدی، اتصال امن Google Drive یا فضای ذخیره‌سازی خصوصی نیاز است.

**YouTube:** ویدئوی عمومی‌ای را بدهید که حق دانلود، تدوین و انتشار آن را دارید. دانلود از YouTube روی IPهای GitHub گاهی به‌دلیل محدودیت سایت موفق نیست؛ در آن صورت فایل را در Drive بگذارید.

## خروجی

```text
output/
├── dashboard.html       گزارش فارسی قابل بازشدن در مرورگر، پیش‌نمایش کلیپ‌ها و متن‌ها
├── clips/
│   ├── clip-01.mp4      کلیپ عمودی 720×1280 با تصویر پس‌زمینه محو
│   └── clip-02.mp4
├── covers/
│   ├── clip-01.jpg      کاور پیشنهادی 1280×720 (برای بررسی دستی)
│   └── clip-02.jpg
├── metadata/
│   ├── clip-01.txt      تیتر، ۳ جایگزین، توضیحات، هشتگ، تگ و کامنت
│   └── clip-01.json     همان اطلاعات برای توسعه نرم‌افزاری
├── cut-list.csv         تایم دقیق برش‌ها در فیلم اصلی
├── manifest.json        گزارش ماشینی کل اجرای پروژه
└── README-OUTPUT.txt
```

کاور JPG **پیشنهاد طراحی** است. بارگذاری یا انتخاب تصویر بندانگشتی برای Shorts ممکن است در اپلیکیشن YouTube و از فریم ویدئو نیاز به اقدام دستی داشته باشد. انتشار خودکار، زیرنویس تایم‌کددار SRT و اصلاح هوشمند قاب چهره‌ها در این MVP وجود ندارد.

## محدودیت‌ها و نکات امنیتی

- GitHub فقط **کد** و خروجی موقت را نگه می‌دارد، نه آرشیو دائمی فیلم‌های شما. در workflow خروجی‌ها فقط **۳ روز** حفظ می‌شوند و بهتر است فوراً آرشیو شوند.
- در پلن رایگان، حجم ذخیره Artifacts و دقیقه‌های اجرای Private repositories سهمیه دارد؛ برای جلوگیری از مصرف بیش از حد، کلیپ‌ها 720p و فشرده ساخته می‌شوند.
- Gemini ممکن است مرز برش، سخن نقل‌شده، تیتر یا حتی برداشتی از گفتار را اشتباه تشخیص دهد؛ **کنترل انسانی اجباری** است.
- برای پردازش ویدئو، یک نسخه سبک در Gemini Files API آپلود و پس از پاسخ برای حذف آن درخواست می‌شود. به سیاست‌های نگهداری داده سرویس خود توجه کنید.
- مدل جایگزین فقط در صورت خطاهای موقتی مانند 429/503 به‌کار می‌رود؛ خطاهای ناشی از نبود دسترسی یا کلید نامعتبر نیاز به اصلاح تنظیمات دارد.
- برای فیلم‌های بسیار بلند، ظرفیت دیسک، زمان و محدودیت هزینه می‌تواند مانع باشد. پیشنهاد آزمایشی: ۵ تا ۲۰ دقیقه ویدئو.
- بدون مجوز حق نشر یا رعایت مقررات پلتفرم، ویدئویی را دانلود/منتشر نکنید.

## اجرای محلی (اختیاری)

این قسمت برای توسعه‌دهنده است؛ برای استفاده عادی GitHub Actions کافی است.

```bash
python -m pip install -r requirements.txt
export GEMINI_API_KEY='YOUR_KEY'
export VIDEO_URL='https://example.com/video.mp4'
export STUDIO_MODE='automatic'
python studio.py
python -m unittest discover -s tests -v
```

## خطاهای رایج

- **No Run workflow**: فایل `.github/workflows/youtube-studio.yml` روی شاخه پیش‌فرض نیست، یا Actions غیر فعال است.
- **Missing repository secret**: کلید `GEMINI_API_KEY` را در بخش Secrets اضافه کنید.
- **Gemini 429 / 503**: سامانه چندبار با فاصله تلاش می‌کند، سپس به Flash-Lite سوییچ می‌کند؛ در صورت تداوم خطا پس از مدتی دوباره اجرا کنید.
- **Model not found / permission denied**: دسترسی مدل یا API key را در AI Studio بررسی و مدل مجاز دیگری تنظیم کنید.
- **Download failed**: لینک مستقیم نیست یا Drive/YouTube مانع دانلود خودکار شده است.
- **No valid segments**: زمان‌های پیشنهادشده با محدوده طول کلیپ منطبق نیستند؛ مقدار min/max را تغییر دهید یا کلیپ را با حالت precut بدهید.
- **DEADLINE_EXCEEDED در Apps Script**: این پروژه اساساً بر پایه Google Apps Script نیست؛ FFmpeg روی Runner گیت‌هاب اجرا می‌شود.

## راه توسعه بعدی

فاز بعد: داشبورد خصوصی با آپلود مستقیم فایل، بازبینی و اصلاح بازه تقطیع، زیرنویس دقیق، اتصال امن Drive و انتشار بعد از تایید در کانال. در MVP فعلی هزینه و پیچیدگی اولیه پایین نگه داشته شده است.
